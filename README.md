# 地产交易游戏AI

`地产交易游戏AI`（`property-trading-game-ai`）是一款原创的单机地产交易棋盘游戏，也是一个可复现的多智能体自对弈研究项目。玩家可以直接完成整局游戏、按需查看实时建议，或观看全部席位由策略控制的对局。

项目不读取、录制或同步第三方游戏进程。棋盘地名、事件文本、角色、图标、声音和界面均按原创虚构城市重新设计。

## 目标体验

- 3–5 人固定规则牌局，一名真人可与多个 AI 对局
- 支持购买、拍卖、租金、税费、抵押、均匀建造、监狱、破产和完整回合结算
- 双方都可发起交易，并可接受、拒绝或在三轮内反报价
- 实时建议可独立开启或关闭；观战模式由 AI 完成全部操作
- 离线优先，无账户或强制联网；牌局保存在本机并可手动导出
- 每局保存随机种子和动作序列，以便确定性回放

## AI 研究路线

现有神经进化策略和零知识 PPO 检查点作为冻结基准保留。新的主线结合随机搜索教师、策略与价值网络、策略蒸馏和联盟自对弈；搜索与模型只能使用玩家可见信息以及未知事件的概率分布。

训练先覆盖 3、4、5 人局，再按人数微调。快速游玩策略用于普通对局，较大搜索预算用于深度思考和上限评测。评测在固定对手、种子和均衡座位下独立运行，并同时报告强度、决策耗时和非法动作数。

## 项目结构

- `app/game-rules.mjs`：确定性的牌局状态转换与合法性校验
- `app/standalone-session.mjs`：单机牌局、合法动作、谈判、公开拍卖及确定性回放
- `app/session-state.mjs`：旧版助手存档迁移与兼容验证
- `app/ai-advisor.mjs`：冻结基准策略的决策适配器
- `shared/board-rules.json`：网页与训练环境共用的固定规则数据
- `training/zero_knowledge/`：冻结的零知识 PPO 基准
- `training/search_pipeline/`：公开信息搜索教师、席位隔离与评测里程碑
- `docs/adr/`：重要架构决定
- `CONTEXT.md`：领域术语和产品边界

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

## 质量检查

```bash
npm test
npm run lint
```

训练配置与命令见 [`training/README.md`](training/README.md)。训练检查点、运行日志和本地工作目录不会提交到仓库。
