# 结合搜索教师、蒸馏与联盟自对弈

一个月训练预算用于追求独立评测中的最高策略强度，不再把纯零知识 PPO 作为最终约束。搜索教师只使用公开信息和未知事件的概率分布生成合成决策，策略与价值网络先跨3、4、5人局共享训练，再按人数微调；快速游玩策略通过蒸馏获得，深度思考与研究评测可以使用更大的搜索预算。

各席位可以共享模型权重，但必须拥有独立记忆、奖励与随机采样，不能共享隐藏状态。现有人工先验模型和零知识 PPO 检查点冻结为基准，不再分配训练算力。训练在约100、300和500 GPU小时运行固定评测并保留最佳检查点；满一个月本身不是发布条件，只有通过合法性、胜率、平均名次和决策耗时门槛的候选策略才成为正式模型。
