# 零知识联盟自对弈训练器

这套训练器与现有 `league-trainer.mjs` 隔离。旧模型继续服务网站，新模型只有在完成独立验证并导出后才会替换线上版本。

“零知识”在本项目中的含义：策略网络只接收公开局面、官方地契数据和合法动作候选；购买、拍卖、建房、抵押和交易没有人工估值公式，也没有模仿旧规则机器人。奖励来自终局名次；课程阶段达到回合上限时，先按官方抵押价与建筑半价执行规则化清算，再确定名次。

## 已覆盖动作

- 3、4、5 人局与统一共享策略；
- 掷骰、连续双骰、监狱三种离开方式；
- 购买与完整多方拍卖；
- 收租、税、机会与社会基金、破产；
- 均衡建房、卖房、抵押和赎回；
- 仅回合玩家主动发起交易，对方接受或拒绝；
- 同一回合可向同一或不同玩家连续提出新报价；
- 地契、现金和监狱通行证交易。

## 模型与训练

策略使用玩家实体和地契实体 Transformer、每位玩家独立循环记忆，以及对可变长度合法动作集合的候选评分。PPO 只优化主策略，其他席位由随机策略、当前策略和历史联盟快照混合组成。训练先使用短局课程，并按累计对局量平滑提高；默认在 25 万局时达到完整的 360 回合上限，批量大小不会改变课程速度。

第一阶段对 3/4/5 人局共享预训练；收敛后用 `--init-from` 从共享检查点分别建立三个人数的微调任务，最终仍导出三套针对性模型。

规则机器人只出现在 `evaluate.py` 的独立评测中，不参与策略训练、奖励塑形或自适应停止判断。

停止条件不是固定局数：达到最低对局量后，只有当前策略对历史联盟的置信胜率达标、连续多轮没有显著提升且学习率退火完成时才停止。默认最低对局量为 200 万局。

## 暂停与恢复

`pause-training.ps1` 会请求安全暂停。训练器完成当前小批次后保存模型、优化器、随机状态、联盟快照和进度，然后释放显卡。再次运行 `start-training.ps1` 会自动恢复。

训练每 20 分钟自动保存检查点；GPU 温度连续三次达到 80°C 时自动安全暂停。`background` 模式使用低于正常的系统优先级，`full` 模式用于电脑空闲时。

首次运行 `setup-training.ps1` 安装官方 CUDA 版 PyTorch。之后使用 `start-training.ps1 -Profile background` 启动、`status-training.ps1` 查看状态、`pause-training.ps1` 安全暂停。
